# AttritionX – Employee Churn Prediction

## 📌 Project Overview

**AttritionX** is a machine learning-based employee churn prediction system designed to analyze employee data and identify patterns associated with employee attrition.

The project uses historical employee information to predict whether an employee is likely to leave an organization. It also provides data analysis and visualizations to help understand employee churn patterns.

## 🎯 Objectives

* Predict employee churn using machine learning.
* Analyze factors associated with employee attrition.
* Identify patterns in employee behavior and demographics.
* Visualize churn trends and prediction results.
* Provide an interactive application for exploring churn predictions.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Streamlit
* Excel

## 📊 Project Features

* Employee data preprocessing and analysis
* Churn prediction using machine learning
* Employee churn visualization
* Gender-based churn analysis
* Prediction result generation
* Interactive dashboard
* User-based churn prediction

## 📂 Project Structure

* `app_dashboard.py` — Interactive dashboard application
* `attrition_app_churn.py` — Churn prediction application
* `customer_data.xlsx` — Employee/customer dataset
* `churn_predictions.xlsx` — Generated churn prediction results
* `app_user_churn.xlsx` — User-level churn data
* `churn_by_gender.png` — Gender-based churn visualization
* `churn_pie_chart.png` — Churn distribution visualization
* `run_attritionx_app.bat` — Application launcher
* `run_attritionx_churn.bat` — Churn application launcher

## 🤖 Machine Learning

The system processes employee data, performs the required preprocessing, and applies machine learning techniques to predict employee churn.

The predictions can be used to identify employees who may have a higher likelihood of leaving, allowing organizations to better understand employee retention patterns.

## 📈 Results & Analysis

The project provides visual insights into employee churn, including overall churn distribution and differences across employee groups.

The generated prediction files can also be used for further analysis and evaluation.

## 🚀 How to Run

### 1. Install the required libraries

```bash
pip install pandas numpy scikit-learn matplotlib streamlit openpyxl
```

### 2. Run the dashboard

```bash
streamlit run app_dashboard.py
```

### 3. Or run the churn application

```bash
streamlit run attrition_app_churn.py
```
